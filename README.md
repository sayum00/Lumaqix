# Lumaqix — Render Ready

1. Upload this project to GitHub.
2. Create a Render Web Service.
3. Build: `pip install -r requirements.txt`
4. Start: `python app/main.py`
5. Add `BOT_TOKEN` from @BotFather.
6. Add `WEBAPP_URL` as your Render HTTPS URL.
7. In @BotFather set the Mini App/Menu Button URL to the same HTTPS URL.
8. If your bot username is not `LumaqixBot`, change it in `app/web/app.js`.

This is a points-based starter, not a real-money investment/withdrawal system.
