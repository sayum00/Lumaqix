Lumaqix UI v2

Replace app/web/index.html and app/web/style.css in the Render project.
The UI uses the existing FastAPI endpoints from the starter: /api/me, /api/daily-gift, /api/open-invite-gift, /api/referral, /api/withdraw.
This package is a frontend/UI upgrade; blockchain deposit watcher, mining scheduler and real auto-withdraw worker are not included.
